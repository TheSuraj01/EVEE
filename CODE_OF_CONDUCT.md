# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and accept
that maintainers get the final call on scope. Accessibility matters here more than in most
projects — many users of voice control rely on it, so dismissiveness about an accessibility
need is treated as a conduct issue.

Report concerns privately to the maintainers via a GitHub private advisory or direct
message. Reports are handled confidentially.
